Features

Everything you need to share instantly

Snaply is built around a single principle: getting from capture to share link as fast as possible.

⚡

Instant Capture

Global hotkey works from any application. No window switching. No context loss. Select your region and you're done.

🔗

One-Click Share

The share link is automatically copied to your clipboard. Paste it anywhere — Slack, Discord, email, anywhere.

☁️

Cloudflare R2 Storage

Files are stored on Cloudflare's global network. Fast delivery for your recipients, wherever they are in the world.

⏱️

Expiring Links

Share links expire automatically. Configure how long links stay alive — from 1 hour to 30 days.

🔒

Password Protection

Sensitive screenshots can be password-protected. Recipients need the password to view or download the file.

📁

File Sharing

Share any file, not just screenshots. Right-click in Windows Explorer and select "Share with Snaply".

📋

Clipboard Detection

Press Ctrl+Shift+V to instantly share whatever image or URL is in your clipboard.

🔄

Auto-Update

Snaply updates itself silently in the background. You always have the latest version with the newest features.

🪟

System Tray

Snaply lives quietly in your system tray. It's always ready but never in your way.

Privacy

Your files belong to you

Snaply is built with privacy as a first-class requirement. We collect only what is necessary to operate the service.

✓

No passive data collection

Snaply never monitors your screen, clipboard, or files unless you explicitly trigger an action.

✓

Direct-to-cloud uploads

Files upload directly from your computer to Cloudflare R2. The Snaply server never sees your file content.

✓

Credentials in Windows Credential Manager

Your Snaply login token is stored securely using the Windows Credential Manager API — not in plain text files.

✓

Automatic expiration

Shared files are automatically deleted from storage when their link expires. Nothing persists indefinitely by default.

✓

Open source

The entire codebase is public on GitHub. You can audit exactly what Snaply does with your data.

FAQ

Common questions

Can't find what you need? Open an issue on GitHub.

Is Snaply free?
Yes. Snaply is free and open source under the MIT license. The desktop app and backend are both freely available on GitHub.
What are the system requirements?
Windows 10 or Windows 11 (64-bit). Approximately 50 MB of disk space. An internet connection is required for uploading and sharing.
Where are my files stored?
Files are stored on Cloudflare R2 object storage — a globally distributed, highly available cloud storage service. Files are stored only for as long as their share link is active.
How long do share links last?
By default, share links expire after 24 hours. You can configure the default expiration in your account settings. Links can also be manually revoked at any time from your dashboard.
What file types can I share?
Snaply supports images (PNG, JPEG, GIF, WebP), videos (MP4, WebM), PDFs, ZIP archives, plain text, and CSV files. File size limit is 100 MB per file.
Is there a storage limit?
Each account has a 1 GB storage quota and a limit of 500 uploads per month. Files that have had their share links expire or deleted no longer count toward your quota.
Why does Windows show a security warning when installing?
This is a Windows SmartScreen warning for software that doesn't have a purchased code signing certificate. This is standard for indie software. You can safely click "More info" → "Run anyway". See our RELEASE.md for details on our signing roadmap.
Can I self-host the Snaply backend?
Yes. The backend is a standard FastAPI + SQLite application. See the README for setup instructions. You'll need a Cloudflare R2 bucket and the corresponding environment variables.
